# M2 账户与注册验收

日期：2026-09-11（恢复工作后复测）。M2 不代表已经可以公开注册运营；默认注册关闭，M3/M4 仍须验收。

## 交付

- `/register`：真实账户注册、用户名规则、密码确认、关闭注册提示、一次性展示恢复码及保存确认。
- `/recover`：以账户名和恢复码重设密码；恢复成功消费旧码、撤销全部会话。
- `/account`：修改密码、轮换恢复码、查看有效会话、退出其他会话。遗留教师可在这里生成恢复码。
- Argon2id 密码哈希；恢复码与会话令牌只保存 SHA-256 哈希，不可逆还原。
- 数据库限流覆盖注册、登录、恢复及敏感密码验证；不信任客户端伪造的转发 IP。当前全站和按账户限流可能影响共享网络/高频使用，后续需结合可信反代和试用负载调优。
- 移除单个启用账户唯一限制，保留现有用户 ID。回滚前若已有多个启用用户会明确拒绝，不自动删人或禁用账户。
- 新注册账户默认没有付费 AI 权限，手工业务不受影响；既有教师权限通过迁移保留。权限管理和配额留在 M4。
- 输入校验响应只含错误位置/类型，不回传密码等输入或校验上下文。

## 本地运行

先完成 `pnpm install` 和 Python 依赖安装，启动 Docker，再运行上述验证命令。脚本临时使用 3101/8101 端口，若被占用请先确认占用服务，不能杀掉未知进程。脚本退出只停止自己创建的服务和临时数据库；不触碰现有数据库卷。

集成部署时由迁移服务升级数据库。`REGISTRATION_ENABLED=false` 默认保留；M3/M4 完成前不要改成对公网开放。初始化 CLI 仍仅供空系统创建第一位可信教师，不是新增普通教师的入口。
