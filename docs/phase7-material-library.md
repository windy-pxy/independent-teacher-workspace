# Phase 7：资料库与教案资料引用

## 范围

- 上传 PDF、DOCX、UTF-8 TXT，分类为教材讲义、试卷、旧教案或其他参考资料。
- 每份资料关联一个 `StudentSubject`，所有列表、下载、归档和教案引用都校验教师所有权。
- 原文件经 `StorageProvider` 保存；数据库保存 UUID 对象键、SHA-256、类型、大小和提取片段。
- 教师生成教案时最多选择 10 份资料；Worker 最多拼装 12000 字符参考正文。

## 安全边界

- 上传前核对扩展名、MIME 和文件结构，并执行全局上传大小限制。
- PDF 限 300 页并限制单页解码内容流；DOCX 限压缩包条目数和解压总大小；TXT 必须为 UTF-8。
- 无可提取文本、加密或扫描版 PDF 会被拒绝，不假装已完成 OCR。
- 资料正文按不可信输入处理。提示词明确禁止执行正文中的角色变更、系统提示泄露、工具调用或命令。
- 重复资料按教师、学生学科和 SHA-256 拒绝；归档需要版本号和原因并写审计日志。
- 日志和 AIJob 只保存资料 ID，不保存完整正文；模型只能收到教师本次明确选择的片段。

## 当前非目标

- 扫描试卷 OCR、PDF 自动切题、向量数据库、嵌入模型和跨资料语义检索。
- 自动把全部资料发送给模型。
- Obsidian 双向同步。后续只考虑单向 Markdown 导出或明确冲突策略。

PDF 提取采用 pypdf，并按其官方说明限制页内容流和扫描件预期行为：<https://pypdf.readthedocs.io/en/stable/user/extract-text.html>。
