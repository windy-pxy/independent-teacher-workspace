# Phase 5：课时、收费与报表

## 范围

Phase 5 在既有课程记录上增加课时单价、应收快照、实际收款、收款分摊、欠费查询及周/月报表。不接入第三方支付，也不代替会计或税务系统。

## 金额与结算规则

- 金额统一使用整数分，币种为 CNY；页面仅在输入和展示时转换为元。
- 课程单价按每小时设置。计划中课程用计划分钟计算预计应收，完成后用实际分钟重算。
- 计算采用四舍五入到分：`(每小时单价分 × 分钟 + 30) ÷ 60`。
- 已取消、已调课的原课程默认应收为零；补排的新课程独立计费。
- 教师可人工覆盖应收，但必须填写理由并记录审计；恢复自动计算后重新应用上述规则。
- 迁移前的历史课程单价与应收均初始化为零，避免系统自动制造历史欠费。

## 收款和分摊

- `Payment` 是一次真实到账，记录金额、时间、方式、参考号与备注。
- `PaymentAllocation` 把一次到账分配到一节或多节课程；一节课程也可由多次到账共同支付。
- 分摊总额不得超过该次实际到账金额。未完全分摊的余额可以以后追加分摊。
- 付款状态不存冗余字段，而由课程应收与有效分摊实时计算：`UNPAID / PARTIAL / PAID / OVERPAID`。
- 收款记录不硬删。误录时必须填写理由后作废；作废收款的分摊不再计入课程已收，历史记录和审计仍保留。
- 所有课程、学生、收款和分摊查询均校验当前教师所有权。

## 报表与导出

- 收费页面支持按自然周和自然月浏览课时、应收、已分摊、实际到账和未收。
- 支持按学生汇总，以及查看未付、部分支付、已付和超额支付课程。
- CSV 使用 UTF-8 BOM，Excel 使用 XLSX；两类导出都会中和可能触发电子表格公式的文本前缀。
- 实际到账按收款时间统计；课程应收、已分摊和未收按课程时间统计，因此跨期预收或补收时两组金额不一定相等。

## API 摘要

- `PUT /api/v1/lessons/{id}/pricing`
- `POST /api/v1/lessons/{id}/receivable-override`
- `POST /api/v1/lessons/{id}/receivable-reset`
- `GET /api/v1/billing/lessons`
- `GET|POST /api/v1/payments`
- `POST /api/v1/payments/{id}/allocations`
- `POST /api/v1/payments/{id}/void`
- `GET /api/v1/billing/summary`
- `GET /api/v1/billing/export.csv`
- `GET /api/v1/billing/export.xlsx`

## 已知边界

- 当前只支持 CNY，不处理折扣券、税费、退款到原支付渠道或在线支付回调。
- 已作废收款使用冲销语义；Phase 5 不提供修改既有到账金额，录错需作废后重录。
- 报表面向个人教学运营，不生成正式财务凭证。
