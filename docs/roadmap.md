# 分阶段路线图

## Phase 0：规划与骨架（已完成）

- 文档、Web/API/Worker、初始迁移、Compose、CI 和基础测试。
- 验收：安装启动、健康检查、迁移往返、lint、类型、测试和构建通过。

## Phase 1：学生、学科、计划和课程（已完成）

- 登录/退出、会话撤销和认证路由保护。
- 学生、学科、StudentSubject、长期计划及版本化调整。
- 课程创建、列表、日历、调课/取消/补课和基础仪表盘。
- 验收：授权隔离、关键 CRUD、调课审计、计划进度聚合测试。
- 已确认产品行为：账户由 CLI 初始化；不实现重复课程；完成课程时由教师确认需要推进的计划条目。

## Phase 2：AI 教案与 Word（当前已实现，待用户验收）

- Mock/OpenAI Responses API 适配器、结构化输出和集中版本化提示词模板。
- 结构化章节教案、局部重生成、编辑、提交审核、批准/驳回和不可变版本。
- 按年级扩展的教师版 DOCX 样式、中文分页、题目/答案分区、示例文档和自动测试。
- 已确认产品行为：暂不固定模板；结构化章节编辑；先使用 Mock 跑通闭环，真实模型由环境变量启用。

## Phase 3：反馈和进度闭环

- 关键词反馈、AI 结构化草稿、差异预览和人工审核。
- 批准事务更新计划、掌握度证据和下次建议；失败全量回滚。

## Phase 4：错题和针对性练习

- 文本/图片错题、视觉识别草稿、知识点和错误原因。
- 复习记录、掌握度统计、针对性题集、答案解析及人工审核。

## Phase 5：课时、收费和报表

- 实际时长、应收快照、收款分摊、欠费和人工调整审计。
- 学生/周/月汇总、CSV/XLSX 导出和月度收入概览。

## Phase 6：部署、备份和安全

- TLS 私有部署、Supabase 可选适配、数据库/文件备份恢复。
- 上传安全、日志脱敏、安全检查、性能检查和端到端验收。
