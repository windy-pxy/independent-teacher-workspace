# 云服务器与域名购买准备

核查日期：2026-09-12。此文是购买指引，不代表已经购买、备案或完成公网部署。

## 先确认，再付款

建议以阿里云为第一候选，把服务器、域名和备案放在同一账户，减少初次配置成本。当前不需要 NATAPP：正式部署后服务运行在云服务器，不再依赖家中电脑和 Docker Desktop 开机。

先与云厂商备案客服确认：本项目是供多个独立教师注册、保存教学资料的软件网站，当前不提供课程售卖、在线支付或学生端。请如实说明业务，确认你的主体资格、网站名称及所需手续，不要按“个人博客”申报。不确定主体是否适用前不要购买多年套餐。

## 建议配置（小规模试用起点，不是容量保证）

- 产品：轻量应用服务器；如果所需配置或备案条件不满足，再选 ECS。
- 地域：主要用户在中国内地，优先选择内地地域；根据主要用户所在地决定。不要只为省备案而把学生资料放到境外。
- 系统：Ubuntu 24.04 LTS，x86_64，系统镜像；无需购买 Windows 或预装建站面板。
- 规格：建议 2 核 / 4 GB 起步；若要在服务器本地构建镜像，优先 4 核 / 8 GB。最终容量通过试用负载验证。
- 磁盘：建议至少 60 GB，具体随附件量增加；备份必须与原服务器分离，不能只存在同一磁盘。
- 网络：确认有公网 IPv4、套餐带宽/流量及超额收费规则。
- 购买时长：先核实备案要求。阿里云当前文档列明用于备案的相关 ECS/轻量服务器通常需要包年包月至少 3 个月；以购买产品实时资格为准。
- 暂不购买 GPU、Redis、额外云数据库、付费 SSL 或高级建站服务。AI 使用模型 API，不在服务器部署大模型。

## 操作步骤

1. 在 [阿里云官网](https://www.aliyun.com/) 注册并完成实名认证，开启账户多因素认证。
2. 联系备案客服确认上述用途与主体资格。
3. 进入 [轻量应用服务器](https://www.aliyun.com/product/swas)，按建议选地域、规格、Ubuntu 系统镜像、时长和数量 1。付款前把隐藏个人信息的配置与价格截图发来核对；注意续费价，不只看首年优惠。
4. 在阿里云域名服务搜索喜欢的 `.com` 或 `.cn` 域名，核对正常注册价与续费价，完成域名持有人实名认证。先买一个即可，不要购买所谓永久域名。
5. 如果服务器在中国内地，按 [备案前期准备](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/overview) 完成所需备案流程，审核通过后再以域名正式开放网站；官方当前说明轻量应用服务器累计购买需至少 3 个月，且未备案前不得提前开放访问。
6. 购买后告知服务器地域、系统、规格、公网 IP 和域名；密码、SSH 私钥、云访问密钥不要发聊天。后续使用本机保存的 SSH 凭据或临时最小权限方式配置。
7. 后续由开发流程完成 Docker Compose、HTTPS、数据库/文件迁移、异地备份和新设备验收。只对外开放必要 Web 端口，SSH 限制来源；数据库 5432 和后端 8000 不对公网开放。

## 依据与未完成事项

- [备案服务器条件](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-server-access-information-check)：检查地域、时长、公网与接入条件。
- [系统镜像列表](https://help.aliyun.com/zh/simple-application-server/product-overview/images)：Ubuntu 24.04 等可用系统。

价格、库存及地域选项会变化，本文不承诺固定价格。备案之外的数据保护、未成年人信息处理及可能适用的其他手续仍需按实际运营方式确认；购买服务器本身不等于合规验收。云端上线前还需通过多教师隔离、安全、恢复与实际跨设备测试。
