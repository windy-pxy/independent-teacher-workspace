# Phase 8：Obsidian 单向 Markdown 导出

## 产品定位

工作台在教师主动操作时，从 PostgreSQL 正式数据生成一个新的 ZIP 时间点快照。解压后的目录可由 Obsidian 直接作为 Vault 打开，适合离线查阅和个人归档；系统不会扫描、覆盖或修改教师已有的 Obsidian 仓库。

PostgreSQL 始终是唯一正式数据源。Obsidian 内的编辑不会写回工作台，也不存在自动合并或冲突解决。

## 导出范围

- 学生档案，以及每名学生关联的学科档案。
- 长期教学计划、结构化条目状态和实际/预计分钟。
- 知识点掌握度。
- 课程时间、类型、状态、时长和特殊要求。
- 仅已批准的教案和课后反馈版本。
- 仅已批准的正式错题及其当前版本。

明确排除密码、API 密钥、登录会话、运行日志、收费与收款明细、AI 调用明细、原始上传附件及归档学生。导出内容仍可能含学生隐私，应只保存在教师控制的设备或加密备份中。

## 文件组织与安全

- 根目录包含说明和学生索引，每个学生与学生学科使用稳定 ID 后缀避免重名冲突。
- Markdown 使用 UTF-8、YAML frontmatter 和 Obsidian Wiki 链接。
- 文件名替换 Windows 禁止字符及 Obsidian 链接特殊字符，拒绝空段、`.` 和 `..`，不拼接客户端路径。
- 查询从当前登录教师拥有且未归档的学生开始，并再次校验学科所有权。
- 下载接口要求登录、Origin/CSRF 校验，响应禁止缓存，并记录仅含数量统计的审计日志。

## 当前限制

- 不包含上传原件或图片；资料库内容不会被复制进 Vault。
- 不做增量导出，每次生成独立完整快照。
- 不创建或更新 Obsidian 插件配置，不依赖第三方社区插件。
- 不支持从 Markdown 导入、双向同步或自动备份到 GitHub。
